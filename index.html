Project overview

This project simulates possible one-year portfolio outcomes using a multivariate-normal Monte Carlo baseline and compares it with GARCH(1,1) volatility modelling plus joint standardized-residual bootstrap sampling. A separate chronological holdout is used to evaluate volatility forecasts.

Methodology explained

01 · Data

Clean and align

Parse dates, sort observations, check invalid/missing prices, calculate returns and align assets by date.

02 · Historical analysis

Estimate risk

Estimate mean returns, volatility, covariance and correlation. These are historical sample estimates.

03 · Monte Carlo

Correlated normal returns

Use a mean vector and covariance matrix to simulate correlated log returns and compound portfolio wealth.

04 · GARCH(1,1)

Conditional volatility

Estimate time-varying variance for each asset using the GARCH recursion.

05 · Residual bootstrap

Joint resampling

Resample aligned standardized-residual vectors by date to retain observed cross-asset residual co-movement.

06 · Validation

Chronological holdout

Fit on training data, forecast one step ahead over the holdout, then compare QLIKE against historical variance.

Core equations and symbol meanings

Simple return: Rₜ = Pₜ / Pₜ₋₁ − 1

Log return: rₜ = ln(Pₜ / Pₜ₋₁)

Portfolio variance: σ²ₚ = wᵀΣw

GARCH(1,1): σ²ₜ = ω + αε²ₜ₋₁ + βσ²ₜ₋₁

Common QLIKE form: L = ln(σ̂²) + y² / σ̂² (normalization/constants may vary; check the implementation).

Pₜ = price at time t; Rₜ = simple return; rₜ = log return; w = portfolio weights; Σ = return covariance matrix; σ²ₚ = portfolio variance; σ²ₜ = conditional variance; ω, α, β = GARCH parameters; εₜ = residual; σ̂² = forecast variance; y² = realized-variance proxy, commonly squared return.

Limitations

  • Historical returns, volatility and correlations may change.
  • Normality can underrepresent heavy tails and extreme joint market moves.
  • GARCH does not capture every market regime or dependence pattern.
  • Bootstrap cannot create unobserved crisis scenarios by itself.
  • Transaction costs, taxes, slippage and market impact may be excluded.
  • QLIKE evaluates variance forecast accuracy against a proxy; it is not a direct profitability test.
  • VaR/Expected Shortfall depends on the loss definition and quantile/tail convention in the implementation.

Reproduce locally

Clone: git clone https://github.com/nasaamit005/monte-carlo-portfolio-risk-simulator.git

Enter project: cd monte-carlo-portfolio-risk-simulator

Create Python 3.12 environment (PowerShell): py -3.12 -m venv .venv then .\.venv\Scripts\Activate.ps1

Install: python -m pip install -r requirements.txt

Run comparison: python .\src\garch_portfolio_simulation.py

Validate forecasts: python .\src\validate_garch_forecasts.py

Tests: python -m pytest .\tests -v
